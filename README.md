# Q3 Vision Aid (Unity XR/MR)

An early-stage Unity project scaffold for a mixed-reality vision-assist application, targeting Meta Quest hardware (Oculus XR plugins, Composition Layers, mixed-reality input actions are pre-configured).

## Status

This is a bootstrap/setup stage: the XR project settings, Oculus configuration, and input action maps are in place, but application scenes and scripts have not been implemented yet. It is a starting point for the vision-assist concept explored more concretely in [android-dual-camera-vision-pipeline-cpp](https://github.com/uzeray/android-dual-camera-vision-pipeline-cpp).

## Stack

Unity · Meta/Oculus XR SDK · Composition Layers · Unity Input System
